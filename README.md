# BookNest Online Library

BookNest is a static web-based library catalogue that allows users to explore a collection of books, search for books by title or author, filter books by category, view book information, and manage borrowing and returning of books.

## Live Deployment

 **Live Website:**  
[BookNest Online Library](https://is-project-2026.github.io/library-catalogue-162484/)

## Features

### Book Catalogue
Displays the available books in the BookNest library collection.

Each book provides relevant information including:

- Book title
- Author
- Category
- Publication year
- Availability status

### Book Search
Users can search the catalogue by:

- Book title
- Author

### Category Filtering
Users can filter the catalogue according to book category.

### Book Borrowing
Users can borrow books that are currently available.

Once a book is borrowed, its availability changes to indicate that it is currently borrowed.

### Book Returning
Users can return books that have previously been borrowed.

The book becomes available again and can subsequently be borrowed.

### Local Storage Persistence
Borrowing and returning information is stored using browser `localStorage`.

This allows the borrowing state to remain available after refreshing the page.

### Responsive Design
The application is designed to work across:

- Desktop computers
- Tablets
- Mobile devices

### Navigation
The application provides navigation between:

- Home
- Catalogue
- About
